01 — What is React Native?

Start with the most important distinction.

⚛️

React Native

An open-source framework for building native mobile applications using React and JavaScript/TypeScript.

📱

Mobile First

It is designed for mobile app development, especially Android and iOS, rather than ordinary web pages.

🧩

Reusable Components

You build interfaces from components such as View, Text, Image, Button, and your own components.


Important: React and React Native are related, but they are not the same thing. React is primarily a UI library for building interfaces; React Native uses React concepts to build mobile applications.

02 — A Short History of React Native

How the technology developed into a mobile development tool.

2013
React appears
Facebook introduced React as an open-source JavaScript library for building user interfaces. React became the conceptual foundation for React Native.
2015
React Native becomes public
Facebook announced React Native publicly at its F8 developer conference and released it as an open-source project for building native mobile apps.
2015+
Community ecosystem grows
React Native expanded beyond Facebook through contributions from developers, companies, libraries, tools, and the wider open-source community.
2020s
Modern React Native
The project continued evolving with a modernized architecture, improved performance and developer tooling, while supporting Android and iOS development.

Why history matters: React Native was created from the idea that developers could use React's component model and JavaScript skills to build mobile interfaces without creating completely separate application UIs for each platform.

05 — Beginner Setup

For classroom learning, students need a manageable workflow.

⚡ Expo — Beginner-Friendly Path

Expo provides tools and services that simplify starting and developing React Native apps. It is a practical option for beginners because students can get to a running app quickly.

Instructions: Setting Up Your React Native Activity

Follow the steps below to create and set up your React Native project using Expo.

Step 1: Create an Activity Folder

Create a new folder on your computer where you will save your React Native activity project.

Step 2: Open Command Prompt

Press Windows + R, type cmd, and press Enter to open Command Prompt.

Step 3: Select the Drive

Go to the drive where you created your activity folder. For example, if your folder is in Drive D, type:

D:

Press Enter.

Step 4: Navigate to Your Activity Folder

Type cd followed by the path of your activity folder. For example:

cd ReactNativeActivities

If your folder is inside another folder, enter the complete path. For example:

cd D:\School\ReactNativeActivities
Step 5: Create Your Expo Project

Once you are inside your activity folder, type the following command:

npx create-expo-app@latest

Press Enter and wait for the setup process to begin.

Step 6: Name Your Application

When prompted, enter a name for your application. Use a name without spaces. For example:

MyFirstApp
Step 7: Install the Required SDK or Dependencies

If prompted to select or install an SDK version or required dependencies, follow the instructions displayed in Command Prompt. Wait until the setup process is complete.

Step 8: Check Your Project Files

Open your activity folder and locate the newly created project folder. Check that the project files and required packages have been created or installed successfully.

Step 9: Locate the Code File

Open the project folder and navigate to:

src → app → index.tsx

Open index.tsx using your code editor. This is the file where you will write and modify your React Native code for the activity.

Reminder: Do not modify other files unless your teacher instructs you to do so.
Step 10: Test Your App on Your Phone

After editing your code, you can test it using Expo Go.

Run the following command to start the app and generate the QR code:

npx expo start

Scan the QR code with your phone:

Then follow the project instructions and run the development server.

🛠️ React Native Community CLI

This path gives more direct control over the native Android/iOS project configuration and is useful when students need native modules or platform-specific configuration.

npx @react-native-community/cli@latest init MyApp

Use this route when your course specifically requires native project configuration.

06 — React Native Learning Roadmap

Follow this sequence for your mobile app programming class.

1. JavaScript → variables → functions → arrays/objects → events → async code
2. React Fundamentals → JSX → components → props → state → hooks
3. React Native UI → View → Text → Image → Pressable/Button → StyleSheet → ScrollView
4. Mobile App Behavior → navigation → forms → lists → state management → local storage
5. Data & APIs → fetch → REST APIs → JSON → authentication → loading/error states
6. Build a Project → plan → wireframe → components → code → test → debug → package/deploy

07 — Your First React Native Component

JSX + React Native components create the UI.

import { View, Text } from 'react-native';

export default function App() {
  return (
    <View>
      <Text>Hello, React Native!</Text>
    </View>
  );
}

Observe: Instead of normal web elements such as <div> and <p>, React Native uses mobile-oriented components such as View and Text.
